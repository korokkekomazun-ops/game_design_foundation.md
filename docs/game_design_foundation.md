# 現地人ロールプレイゲーム 基礎整理

## 目的

このゲームは、圧倒的な異界勢力が現れた世界で、プレイヤーが「ただ一人の現地人」として生きるロールプレイを中心にする。

原作的な魅力は以下にある。

- 職業や種族に細かいレベルがあり、世界の住人に明確な格差がある
- 生まれつきの希少能力があり、本人の人生を大きく変える
- レベル上限が存在し、努力だけでは越えられない壁がある
- 強者は理不尽に強く、弱者は情報・立場・交渉・運で生き延びる
- 現地人にとって、超越者の行動は神話や災害に近い

本作ではこれらを、独自設定として次の4本柱に整理する。

1. 職業
2. 血統・種族
3. 天賦
4. レベル上限

さらに、世界に厚みを出すために次の3要素を重視する。

5. アイテム
6. 召喚・契約
7. 人間関係・信頼

## 基本用語

| 用語 | 意味 |
|---|---|
| 総合Lv | その人物の総合的な成長段階 |
| 職業Lv | 個別職業ごとの習熟度 |
| 器量上限 | その人物が到達できる総合Lvの上限 |
| 天賦 | ごく一部の人物が生まれ持つ特殊な才能 |
| 位階 | 魔法・祈祷・異能の強さの段階 |
| 格 | 戦闘力だけでなく、社会的影響力や恐怖の強さも含む存在感 |
| 現地人 | この世界で生まれ、この世界の常識の中で生きてきた者 |
| 異界勢力 | 世界の外から来たように見える超越的な組織・個人・軍勢 |

## 種族・血統

種族と血統は、初期能力、器量上限、社会的扱い、習得できる職業に影響する。

ただし、本作の主人公は基本的に現地人であるため、種族差は「プレイヤーを最強にするため」ではなく、「生まれの制約と立場の違い」を表す。

### 種族分類

| 種族分類 | 例 | 強み | 弱み | 社会的扱い |
|---|---|---|---|---|
| 人間 | 農民、兵士、商人、神官 | 職業選択が広い | 肉体的には平凡 | 多くの国で標準種族 |
| 亜人 | 獣人、蜥蜴人、角人 | 肉体や感覚に優れる | 差別や警戒を受ける | 地域により市民、奴隷、敵 |
| 森民 | 長耳族、樹民、森の混血 | 感覚、弓、精霊儀礼 | 都市社会に弱い | 森の外では異物扱い |
| 地底民 | 小人族、鉱山氏族 | 工芸、暗視、耐久 | 広域移動が苦手 | 職人として重宝される |
| 魔性血統 | 悪魔混じり、呪血、魔獣混血 | 魔法適性や異常耐性 | 教会や民衆に疑われる | 露見すると危険 |
| 聖別血統 | 聖者の末裔、神殿血族 | 信仰職と治癒に強い | 教義と期待に縛られる | 保護と監視を受ける |
| 古代血統 | 失われた王家、古代種の末裔 | 器量上限が高い場合がある | 政治的に利用される | 発見されると争奪対象 |
| 異界混入 | 異界遺物の影響を受けた家系 | 法則外の天賦が出やすい | 汚染、監視、処分対象 | 存在自体が機密 |

### 血統の濃さ

血統は「ある/ない」ではなく濃さで扱う。

| 濃さ | 内容 | ゲーム上の影響 |
|---|---|---|
| 痕跡 | 伝承や外見に少し残る | 小さな補正、会話差分 |
| 薄血 | 能力や体質に現れる | 初期能力や天賦候補に影響 |
| 半血 | 社会的にも明確に分かる | 差別、保護、専用イベント |
| 濃血 | 種族特性が強く出る | 器量上限や職業制限に影響 |
| 先祖返り | 伝説的特徴が発現する | 強力だが発見されると危険 |

### 種族と器量上限

| 種族分類 | 器量上限の傾向 | 備考 |
|---|---|---|
| 人間 | 平凡から才人まで幅広い | 天賦次第で大きく化ける |
| 亜人 | 肉体系の上限が高め | 社会職の成長機会が少ない |
| 森民 | 感覚・精霊系に強い | 都市や軍制には不向き |
| 地底民 | 職人・防御・耐久に強い | 魔法系は血統差が大きい |
| 魔性血統 | 魔法・支配・代償系に強い | 疑念と迫害を受けやすい |
| 聖別血統 | 信仰・治癒・精神に強い | 教会に囲い込まれやすい |
| 古代血統 | 上限が高くなりうる | 政治イベントを呼び込む |
| 異界混入 | 不安定だが高レア天賦が出やすい | 汚染と接触リスクが高い |

### 血統サンプル

| 名称 | 分類 | 効果 | 危険 |
|---|---|---|---|
| 灰狼の薄血 | 亜人 | 夜間の嗅覚と追跡に補正 | 獣人狩りの対象になる地域がある |
| 森契りの家 | 森民 | 精霊型魔物との交渉に補正 | 森を裏切る選択で強い反動 |
| 鉄脈氏族 | 地底民 | 鉱物鑑定と鍛冶職に補正 | 地上貴族に技術を狙われる |
| 黒角の隔世 | 魔性血統 | 召喚・契約文の理解が早い | 神殿に露見すると審問対象 |
| 白燭の末裔 | 聖別血統 | 治癒と死霊対処に補正 | 奇跡を求める民衆に潰される |
| 失冠王家の血 | 古代血統 | 立場と王命系天賦に関係 | 反乱の旗印にされる |
| 空門症 | 異界混入 | 異界品の違和感を察知する | 異界存在に見つかりやすい |

## レベル帯

プレイヤーが現地人であることを強調するため、強さの階段は広く取る。

| 総合Lv | 呼称 | 目安 | 現地人から見た印象 |
|---:|---|---|---|
| 1-3 | 日常人 | 農民、子供、雑用係 | 普通の人 |
| 4-7 | 駆け出し | 見習い兵、 apprentice職人 | 少し頼れる |
| 8-12 | 熟練者 | 正規兵、村の名手、地方神官 | 村や町では強い |
| 13-18 | 達人 | 騎士、上級冒険者、熟練魔術師 | 地方の英雄 |
| 19-25 | 英傑 | 宮廷魔術師、将軍、聖騎士 | 国が動く |
| 26-35 | 伝説級 | 英雄譚の主役、怪物討伐者 | 人間離れ |
| 36-50 | 神話級 | 大国の切り札、古代種 | 歴史が変わる |
| 51+ | 異界級 | 異界勢力、超越存在 | 理解不能 |

現地人プレイヤーの通常上限はLv15前後に置く。特別な出自・天賦・契約・呪いがあっても、初期構想ではLv25程度を現地人到達域の上限にする。

## 職業分類

職業は「生活職」「戦闘職」「学術職」「信仰職」「裏社会職」「特殊職」に分ける。

職業は単なる肩書きではなく、次の4つを同時に表す。

| 要素 | 内容 |
|---|---|
| 技能 | 何ができるか |
| 所属 | どの共同体に受け入れられるか |
| 視点 | 世界をどう解釈するか |
| 制約 | 何に縛られるか |

同じLv10でも、農民Lv10、兵士Lv10、書記Lv10では生き残り方がまったく違う。

### 生活職

生活職は弱く見えるが、現地人ロールプレイでは重要。交渉、収入、信用、食料、隠れ場所、身分証明に関わる。

| 職業 | 主な能力 | 強み | 弱み |
|---|---|---|---|
| 農民 | 体力、土地勘、食料管理 | 村社会で信用される | 都市や貴族社会に弱い |
| 職人 | 製作、修理、鑑定 | 道具を作れる | 戦闘は不得手 |
| 商人 | 交渉、相場、移動網 | 情報と金に強い | 暴力に弱い |
| 薬師 | 調合、治療、毒知識 | 生存力が高い | 材料不足に左右される |
| 役人 | 文書、法、徴税 | 権力機構に入れる | 民衆から疑われやすい |
| 使用人 | 礼法、観察、潜入 | 権力者の近くに行ける | 身分が低い |

### 戦闘職

戦闘職は直接的に生存率を上げるが、強者に見つかる危険も増える。

| 職業 | 主な能力 | 強み | 弱み |
|---|---|---|---|
| 民兵 | 槍、集団行動、見張り | 低コストで戦える | 単独戦闘に弱い |
| 兵士 | 武器、防具、規律 | 安定して強い | 命令系統に縛られる |
| 騎士 | 剣、乗馬、威圧 | 社会的地位が高い | 責任と名誉に縛られる |
| 狩人 | 弓、罠、追跡 | 野外生存に強い | 正面戦闘に弱い |
| 傭兵 | 実戦、脅し、逃走判断 | 現実的な判断が得意 | 信用されにくい |
| 冒険者 | 探索、対魔物、柔軟性 | イベント対応力が高い | 死亡率が高い |

### 学術職

学術職は世界理解に強い。異界勢力を「神話」ではなく「構造」として理解できる可能性がある。

| 職業 | 主な能力 | 強み | 弱み |
|---|---|---|---|
| 書記 | 読解、記録、暗号 | 情報整理に強い | 荒事に弱い |
| 魔術師 | 魔法、解析、儀式 | 問題解決力が高い | 準備と資源が必要 |
| 学者 | 歴史、言語、分類 | 異常の理解に近づく | 実用まで時間がかかる |
| 錬金術師 | 変成、薬品、素材加工 | 希少な解決策を作れる | 設備依存 |

### 信仰職

信仰職は社会的信用と精神耐性が強い。神、奇跡、死者、呪いに関する事件で重要になる。

| 職業 | 主な能力 | 強み | 弱み |
|---|---|---|---|
| 神官 | 治癒、説法、儀礼 | 民衆に信頼される | 教義に縛られる |
| 異端審問官 | 尋問、対呪術、威圧 | 異常事件に強い | 敵を作りやすい |
| 巡礼者 | 旅、信仰、噂 | 広域情報に強い | 定住地の後ろ盾が弱い |
| 聖騎士 | 武力、信仰、士気 | 仲間を支えられる | 価値観が折れると脆い |

### 裏社会職

弱者が権力から逃げる、または権力の隙間で生きるための職業。

| 職業 | 主な能力 | 強み | 弱み |
|---|---|---|---|
| 盗賊 | 解錠、隠密、逃走 | 危険地帯から抜け出せる | 捕まると終わる |
| 密偵 | 変装、盗聴、報告 | 情報戦に強い | 忠誠を疑われる |
| 闇商人 | 密輸、禁制品、賄賂 | 非合法資源に触れる | 正規権力に弱い |
| 暗殺者 | 毒、急所、潜伏 | 格上にも一矢報いる | 失敗時の反動が大きい |

### 特殊職

特殊職は条件を満たすと出現する。現地人としては希少で、物語の分岐点になる。

| 職業 | 解放条件 | 特徴 |
|---|---|---|
| 災厄目撃者 | 異界級存在を直接目撃して生還 | 恐怖耐性と異常察知を得る |
| 王国の協力者 | 異界勢力に情報提供する | 保護と嫌悪を同時に得る |
| 反逆の火種 | 占領地で抵抗組織に参加 | 仲間と危険な希望を得る |
| 禁忌研究者 | 異界の遺物を解析する | 知識と汚染が増える |
| 供物候補 | 超越者に気に入られる | 恩恵と所有物扱いを受ける |
| 生還譚の語り部 | 大事件から複数回生還 | 噂が自分を守り、縛る |

### 職業系譜

職業は横に広げるだけでなく、低位職から上位職へ伸びる。

| 系譜 | 低位職 | 中位職 | 上位職 | 到達後の立場 |
|---|---|---|---|---|
| 村落 | 農民 | 村役、地主代行 | 開拓指導者 | 食料と避難民を動かせる |
| 医療 | 薬師見習い | 薬師 | 王立薬師、毒師 | 命を救い、毒も扱える |
| 軍事 | 民兵 | 兵士 | 騎士、百人隊長 | 命令権と戦場責任を持つ |
| 冒険 | 荷運び | 冒険者 | 探索隊長、魔物狩り | 危険地帯に入れる |
| 学術 | 書記 | 学者 | 宮廷学士、禁忌研究者 | 異常を記録・解析できる |
| 魔法 | 魔術徒弟 | 魔術師 | 儀式魔術師、召喚師 | 現実に干渉できる |
| 信仰 | 祈祷係 | 神官 | 異端審問官、聖騎士 | 正義の名で人を裁ける |
| 裏社会 | 使い走り | 盗賊、闇商人 | 密偵、暗殺者 | 法の外側で動ける |
| 占領地 | 避難民 | 協力者、反逆者 | 代官、抵抗指導者 | どちら側の人間か問われる |

### 職業の格

同じ分類でも、職業には社会的な格がある。格が高いほど強いが、自由が減る。

| 格 | 例 | 強み | 制約 |
|---|---|---|---|
| 雑役 | 使用人、荷運び、農奴 | 目立たない | 発言権がない |
| 自立職 | 薬師、職人、狩人 | 自分の技能で稼げる | 後ろ盾が弱い |
| 組織職 | 兵士、神官、役人 | 保護と権限がある | 命令に縛られる |
| 特権職 | 騎士、宮廷魔術師、貴族書記 | 高い信用と装備 | 政治に巻き込まれる |
| 禁忌職 | 暗殺者、禁忌研究者、異端召喚師 | 格上に届く手段を持つ | 露見すると破滅する |

### 職業シナジー

複数職業の組み合わせで、現地人らしい強みが生まれる。

| 組み合わせ | 生まれる強み | 例 |
|---|---|---|
| 薬師 + 使用人 | 貴族家で治療名目の聞き込みができる | 毒殺事件の調査 |
| 書記 + 密偵 | 証拠を偽装・解読・保管できる | 占領軍への内通記録 |
| 狩人 + 災厄目撃者 | 異常な痕跡を追える | 異界獣の移動経路を読む |
| 神官 + 反逆の火種 | 信仰を抵抗の旗印にできる | 村人の士気維持 |
| 商人 + 闇商人 | 表と裏の物流を使える | 禁制品の逃走路確保 |
| 兵士 + 王国の協力者 | 占領統治の現場に入れる | 命令書の改ざんや密告 |

## 職業Lvの上限

職業ごとに標準上限を決める。

| 職業種別 | 標準上限 | 備考 |
|---|---:|---|
| 一般生活職 | 10 | 普通の人生で到達可能 |
| 専門生活職 | 15 | 職人、薬師、役人など |
| 一般戦闘職 | 10 | 民兵、狩人など |
| 正規戦闘職 | 15 | 兵士、騎士、傭兵など |
| 高度戦闘職 | 20 | 聖騎士、上級冒険者など |
| 魔法・信仰職 | 15 | 資質と教育が必要 |
| 上級魔法・信仰職 | 25 | 現地人としては希少 |
| 裏社会職 | 15 | 環境依存が強い |
| 特殊職 | 5-10 | 少ないLvでも影響が大きい |

重要なのは、総合Lvは職業Lvの合計であっても、単純な戦闘力ではないこと。農民Lv8 + 薬師Lv6 + 災厄目撃者Lv2 の人物は、剣では弱いが生存力と判断力が高い。

## 天賦

天賦は生まれつきの希少能力。原則として後天的に取得できない。

天賦はレア度が高いほど、明確に強力なものに分類する。ただし、強い天賦ほど本人の人生を周囲が放っておかない。低レアは生活を助け、高レアは戦局・政治・異界勢力の関心に触れる。

### 天賦の希少度

| レア度 | 出現率の目安 | 強さ | 影響 |
|---|---:|---|---|
| 微光 | 1/100 | 生活補助級 | 少し有利。村や職場で便利がられる |
| 希少 | 1/1,000 | 専門技能級 | 職業適性が大きく変わる。町で噂になる |
| 英雄 | 1/10,000 | 戦術・政治級 | 国や組織が確保したがる |
| 伝説 | 1/100,000 | 戦略級 | 戦争、王位、宗教問題に関わる |
| 異端 | 不明 | 法則干渉級 | 現地の常識を外れる。異界勢力にも観測されうる |

### 天賦カテゴリ

| カテゴリ | 低レアの例 | 高レアの例 | 役割 |
|---|---|---|---|
| 感覚系 | 嘘の気配、魔力の残り香 | 死線予知、異界視 | 隠された情報を得る |
| 肉体系 | 毒耐性、怪力 | 超再生、巨人殺しの筋力 | 生存力と戦闘力を上げる |
| 技能系 | 道具の癖を読む | 技能模倣、熟練圧縮 | 職業成長を跳ね上げる |
| 魔法系 | 属性親和、低位魔法補助 | 位階突破、無詠唱高位化 | 魔法の限界を越える |
| 社会系 | 覚えられにくい、警戒されにくい | 群衆扇動、王命の声 | 人と組織を動かす |
| 運命系 | 危機感知、幸運 | 死亡回避、重要因果への介入 | 物語の流れを曲げる |
| 支配系 | 小動物に好かれる | 魔物服従、契約強制 | 召喚や魔物との関係を変える |
| 代償系 | 嘘が苦手、恐怖が薄い | 不死性の欠片、魂の抵当 | 強大な力と不自由を両立する |

### レア度別の設計基準

| レア度 | 効果範囲 | 戦闘影響 | 社会影響 | 物語上の扱い |
|---|---|---|---|---|
| 微光 | 自分だけ | 小 | 小 | 個性、職業補助 |
| 希少 | 自分と周囲数人 | 中 | 中 | 人生の進路を変える |
| 英雄 | 小隊・町・事件単位 | 大 | 大 | 組織が囲い込む |
| 伝説 | 都市・戦場・国家単位 | 特大 | 特大 | 歴史を動かす |
| 異端 | 法則・魂・異界接触 | 不定 | 致命的 | 保護、封印、処刑、崇拝の対象 |

### 天賦サンプル

| 名称 | レア度 | カテゴリ | 効果 | 代償・制限 |
|---|---|---|---|---|

## 強さの評価軸

総合Lvだけで勝敗を決めない。現地人ロールプレイでは、次の5軸を使う。

| 軸 | 内容 | 高いとできること |
|---|---|---|
| 武力 | 戦闘能力 | 魔物や兵士と戦う |
| 知識 | 解析・記録・歴史理解 | 正しい判断をする |

| 隠密 | 逃走・潜伏・偽装 | 生き延びる |

異界級存在に対して、武力はほぼ無意味でも、知識・立場・隠密・精神が生死を分ける。

## 魔物

魔物は経験値を落とす敵ではなく、世界の危険、資源、信仰、噂、政治を動かす存在にする。

現地人にとって魔物は「討伐対象」である前に、「近づいてよいか判断する対象」。倒すより、避ける、誘導する、情報を売る、素材を拾う、誰かに押しつけるほうが現実的な場面も多い。

| 魔獣型 | 影豹、雷角鹿、霧喰い | 魔力を帯びた獣。素材価値が高い | 専門狩人、魔術師の同行 |
| 悪魔型 | 小悪魔、契約魔、誘惑者 | 契約と代償を使う | 契約文、異端審問、沈黙 |

## 対戦形式

本作の対戦は、正面戦闘だけではない。

現地人プレイヤーは弱いため、敵を倒すよりも、状況を作る、情報で勝つ、相手の目的をずらす、第三者を動かすことが重要になる。

### 対戦の種類

| 種類 | 相手 | 勝利条件 | 失敗時 |
|---|---|---|---|
| 戦闘 | 魔物、兵士、賊 | 相手を倒す、追い払う、耐える | 負傷、死亡、悪評 |
| 逃走 | 魔物、追手、暴徒 | 距離を取る、隠れる、安全圏へ入る | 物資喪失、捕縛、同行者死亡 |
| 交渉 | 現地人、亜人、知性ある魔物 | 条件を引き出す、時間を稼ぐ | 不利な約束、疑念上昇 |
| 情報戦 | 役人、密偵、神殿、商人 | 証拠を得る、隠す、流す | 密告、偽情報、信用低下 |
| 儀式戦 | 死霊、精霊、召喚存在 | 封じる、鎮める、契約する | 汚染、呪い、召喚事故 |
| 集団対立 | 村、守備隊、神殿、難民 | 群衆を動かす、暴動を止める | 暴力化、処刑、追放 |
| 環境戦 | 火事、飢饉、無音地帯、魔物圧 | 被害を抑える、経路を確保する | 地域崩壊、移動不能 |

### 対戦の基本解決

対戦は、能力値と状況修正を比べて解決する。

| 要素 | 内容 |
|---|---|
| 基礎能力 | 武力、知識、立場、隠密、精神 |
| 職業補正 | 職業Lvや職業シナジー |
| 準備 | アイテム、情報、地形、味方、罠 |
| 相性 | 魔物分類、相手の身分、魔法系統 |
| 圧力 | 魔物圧、食料圧、軍事圧、神殿圧、異界圧 |
| 代償 | 勝っても失うもの。物資、信頼、体力、疑念など |

勝敗は二択にしない。できるだけ「成功」「代償つき成功」「保留」「失敗」「大失敗」に分ける。

### 結果段階

| 結果 | 内容 |
|---|---|
| 成功 | 目的を達成し、追加利益も得る |
| 代償つき成功 | 目的は達成するが、物資・体力・信頼などを失う |
| 保留 | その場はしのぐが、問題が後日に残る |
| 失敗 | 目的を達成できず、不利な状態になる |
| 大失敗 | 負傷、死亡、捕縛、重要NPC喪失など |

### 魔物との対戦

魔物相手の対戦では、事前情報がもっとも重要。

| 対応 | 必要なもの | 有効な相手 | 危険 |
|---|---|---|---|
| 正面戦闘 | 武力、防具、仲間 | 低脅威の獣型、亜人型 | 格上にはほぼ無謀 |
| 罠 | 知識、隠密、道具、時間 | 獣型、魔獣型、本能型 | 設置中に襲われる |
| 退魔 | 信仰、聖印、儀式 | 死霊型、呪い | 教義外だと効かない |
| 交渉 | 言語、立場、贈り物 | 亜人型、個人知能、精霊型 | 相手の価値観を誤る |
| 誘導 | 地形、餌、火、音 | 獣型、群れ型 | 被害先を選ぶ倫理問題 |
| 召喚対抗 | 契約知識、魔法、天賦 | 悪魔型、召喚魔物 | 契約穴を突かれる |
| 天賦使用 | 高レア天賦、精神 | 格上魔物、魔法持ち | 認識度や汚染度が上がる |

### 現地人との対戦

現地人との対立は、殺せば終わりではない。社会が反応する。

| 相手 | 主な強み | 有効な対策 | 危険 |
|---|---|---|---|
| 村人集団 | 数、噂、土地勘 | 信頼、食料、説得 | 暴徒化、追放 |
| 守備隊 | 武力、法、検問 | 証明書、上官、賄賂 | 逮捕、徴用 |
| 役人 | 文書、権限、記録 | 証拠、法律知識、コネ | 罪を作られる |
| 神殿 | 信仰、治癒、異端審査 | 寄進、信頼、儀礼 | 異端扱い |
| 商人組合 | 物資、金、物流 | 取引、信用、情報 | 借金、出禁 |
| 冒険者 | 武力、自由行動 | 依頼、報酬、名声 | 乱暴な解決 |
| 裏社会 | 密輸、脅迫、逃走路 | 利害、秘密、裏取引 | 弱みを握られる |
| 貴族 | 身分、兵、法外な影響力 | 礼法、証拠、庇護者 | 切り捨て、処刑 |

### 戦闘ラウンドの簡易モデル

正面戦闘が必要な場合も、複雑な戦術ゲームにはしすぎない。

1回の戦闘は、3段階で処理する。

| 段階 | 内容 | 例 |
|---|---|---|
| 接敵前 | 情報、距離、奇襲、逃走可否を決める | 足跡を読めたので先制罠を置く |
| 衝突 | 攻撃、防御、魔法、天賦、仲間行動を処理する | 灰狼の群れを槍と火で押し返す |
| 後始末 | 負傷、素材、目撃者、評判を処理する | 勝ったが村人に危険人物と思われる |

### 戦闘行動

| 行動 | 使う能力 | 効果 |
|---|---|---|
| 攻撃 | 武力 | 相手を傷つける、追い払う |
| 防御 | 武力、精神 | 被害を抑える、仲間を守る |
| 観察 | 知識 | 弱点、行動目的、逃走経路を見つける |
| 隠れる | 隠密 | 標的から外れる、奇襲準備 |
| 指示 | 立場、信頼 | 仲間や群衆を動かす |
| 交渉 | 立場、知識、精神 | 戦闘を止める、条件を変える |
| 魔法 | 知識、精神、位階 | 攻撃、補助、封印、治癒 |
| アイテム | 物資、知識 | 消耗品や遺物で状況を変える |
| 天賦 | 天賦ごとの能力 | 格上への逆転手段になる |
| 逃走 | 隠密、体力 | 戦闘から離脱する |

### 格上への対抗

格上の魔物や現地権力者には、通常の勝利を狙わない。

| 対抗方法 | 内容 |
|---|---|
| 条件勝利 | 倒すのではなく、1分耐える、門まで逃げる、証拠を渡す |
| 弱点勝利 | 素材、伝承、地形、契約穴を突く |
| 代理勝利 | 守備隊、神殿、冒険者、別の魔物を動かす |
| 取引勝利 | 物資、情報、人質、秘密で相手の目的を変える |
| 天賦勝利 | 魔法無力化、異位階魔法、ランダム生成品で一時的に覆す |
| 犠牲勝利 | NPC、物資、名誉、居場所を失って目的だけ達成する |

### 対戦で残すもの

対戦後には、必ず世界に傷跡を残す。

| 残るもの | 内容 |
|---|---|
| 負傷 | 体力低下、後遺症、治療イベント |
| 噂 | 勇敢、卑怯、異端、裏切りなど |
| 証拠 | 血、魔力痕跡、文書、目撃者 |

## 魔法体系

魔法は万能の便利能力ではなく、教育、触媒、詠唱、位階、社会的許可によって管理される専門技術にする。

現地人にとって魔法は「知っている者だけが使える力」であり、同時に「知らない者から恐れられる力」でもある。

### 魔法の位階

位階は魔法の強さと難度を表す。高位階ほど強力だが、準備、才能、資源、政治的許可が必要になる。

| 位階 | 呼称 | できること | 現地人から見た印象 |
|---:|---|---|---|
| 0 | 生活術 | 火種、乾燥、清掃、簡易検知 | 便利な小技 |
| 1 | 初等 | 小治癒、灯火、小火球、防寒 | 町の専門職 |
| 2 | 実用 | 解毒、拘束、隠蔽、低級召喚 | 冒険者や神官の力 |
| 3 | 戦術 | 範囲攻撃、結界、死霊退散 | 戦場で意味を持つ |
| 4 | 上級 | 飛行、精神防御、強力な治癒 | 貴族や軍が囲う |
| 5 | 宮廷 | 都市防衛、広域儀式、契約召喚 | 国家の資産 |
| 6 | 英雄 | 蘇生に近い奇跡、大規模破壊 | 歴史に残る |
| 7+ | 神話 | 法則変更、軍勢召喚、封印破り | 現地人には神話 |
| 異界 | 不明 | 現地法則外の現象 | 理解不能、記録困難 |

プレイヤーが通常到達できるのは、かなり恵まれても2から3位階程度。天賦、遺物、契約、異界汚染が絡むと一時的に上位へ触れられる。

### 魔法系統

| 系統 | 内容 | 得意な職業 | リスク |
|---|---|---|---|

## 召喚・契約

召喚は、現地人にとって「強力な味方を呼ぶ手段」ではなく、「自分より強いものと関係を持ってしまう危険な技術」とする。

召喚された存在には意志・要求・恐怖・忠誠がある。完全に都合よく動くものは少ない。

## 人間関係・信頼

### 友人関係の魅力

友人や仲間は、単なるパーティメンバーではなく、プレイヤーに選択の重さを与える。

- 自分だけなら逃げられるが、友人を連れると遅れる
- 友人の正義感が危険な行動を呼ぶ
- 信頼していた相手が、家族を守るために密告する
- 敵対勢力の中に、個人的には信頼できる人物がいる
- 召喚存在や異界勢力の配下とも、奇妙な友情が生まれる

## 1. 最初の舞台

### 舞台案

最初の舞台は、国境に近い城塞都市と周辺村落にする。

仮称: 灰境地方

灰境地方は、王国の端にある寒冷な辺境。森、古い街道、放棄された砦、鉱山跡、神殿領、亜人部族の縄張りが入り組んでいる。中央から見れば田舎だが、現地人にとっては世界そのもの。

### 中心拠点

仮称: 城塞都市ヴェルツ

| 要素 | 内容 |
|---|---|
| 役割 | 国境警備、交易、避難民の受け入れ |
| 支配者 | 辺境伯代理と軍司令官 |
| 重要組織 | 守備隊、神殿、商人組合、冒険者組合、魔術師詰所 |
| 問題 | 食料不足、難民、魔物増加、密輸、政治不信 |
| プレイヤーの立場 | 都市の下層、村、神殿、守備隊、森などから関わる |

### 周辺地域

| 地域 | 特徴 | 主なイベント |
|---|---|---|
| 灰麦村 | 食料生産地。主人公の出身候補 | 難民受け入れ、魔物被害、徴発 |
| 旧街道 | 王都へ続く道。今は危険 | 商隊襲撃、逃亡、密書運搬 |
| 黒森 | 森民と魔獣がいる | 狩猟、精霊交渉、失踪事件 |
| 鉄鳴り鉱山 | 廃坑と地底民の古い坑道 | 遺物発見、魔物巣、密輸 |
| 白燭神殿 | 治癒と葬儀を担う | 死霊事件、信仰対立、避難民保護 |
| 砕け砦 | 過去の戦争で捨てられた砦 | 異界勢力の斥候、召喚痕跡 |

### 舞台の初期状況

| 状況 | 内容 |
|---|---|
| 食料 | 足りない。村からの徴発が増える |
| 治安 | 表向きは保たれているが、夜は危険 |
| 情報 | 王都方面の噂が錯綜している |
| 魔物 | 通常より人里に近づいている |
| 神殿 | 負傷者と死者の対応で限界 |
| 軍 | 国境防衛か都市防衛かで割れている |
| 民衆 | 何か大きな災厄が来ると感じている |

### 舞台の魅力

- 都市、村、森、神殿、砦が近く、出自ごとの導線を作りやすい
- 弱い現地人でも、情報を持つだけで重要人物になれる
- 魔物被害と政治不安を、異界勢力の前兆として使える
- 逃げる、残る、密告する、調査する、保護を求める選択が自然に生まれる

## 2. 異界勢力の性質

### 基本方針

異界勢力は、最初から全面的に登場させない。

プレイヤーはまず、噂、痕跡、命令書、異常な魔物、消えた村、妙に礼儀正しい使者などを通して存在を知る。正体が分からない段階を長く取り、現地人視点の恐怖を保つ。

プロトタイプでは、黒冠宮は「ただいるかもしれない」という匂わせに留める。直接の戦闘相手にも、会話相手にも、攻略対象にもまだしない。1章目の問題は、魔物、現地人、現地組織、食料不足、疑念、裏切りで成立させる。

### 異界勢力案

仮称: 黒冠宮

黒冠宮は、空に浮かぶ黒い城ではなく、世界の外側から落ちてきたような巨大な地下宮殿とする。地上からは黒い塔、地割れ、無音の森、消えた街道として観測される。

| 要素 | 内容 |
|---|---|
| 性質 | 高度な魔法文明、階層社会、非人間的倫理 |
| 目的 | 現地世界の調査、資源確保、支配実験 |
| 行動 | 斥候派遣、現地人の選別、魔物の制御、貴族への接触 |
| 恐怖 | 力よりも、何を考えているか分からないこと |
| 魅力 | 残酷だが秩序があり、庇護者にもなりうる |

### 異界勢力の階層

| 階層 | 呼称 | 現地人から見た役割 |
|---|---|---|
| 頂点 | 黒冠の主 | 神話級。直接会うものではない |
| 最高幹部 | 宮の守護者 | 国家を一人で揺らす存在 |
| 管理者 | 執政官、研究官、軍監 | 現地支配や実験の責任者 |
| 使者 | 仮面の使節、契約官 | 貴族や神殿に接触する |
| 斥候 | 無貌兵、影従者 | 目撃者が少ない |
| 端末 | 黒門の影、異界虫 | 痕跡や異常現象として現れる |

### 現地人への態度

| 態度 | 内容 | プレイヤーへの影響 |
|---|---|---|
| 無視 | 虫や背景のように扱う | 巻き込まれないが、踏み潰される |
| 観察 | 反応や行動を記録される | 選択が後で評価される |
| 利用 | 情報提供者、案内人、実験対象にする | 保護と危険が同時に来る |
| 保護 | 有用または興味深い個体として守る | 周囲から裏切り者扱いされる |
| 処分 | 不要、危険、邪魔と判断される | 逃亡か従属しかない |

### 異界勢力の見せ方

| 段階 | プレイヤーが知ること | 例 |
|---|---|---|
| 1 | 噂 | 王都方面から来た難民が黒い軍勢を語る |
| 2 | 痕跡 | 魔法では説明しづらい焼け跡や無音地帯 |
| 3 | 端末 | 黒門の影、異界虫、改造された魔物 |
| 4 | 使者 | 人間の言葉を話す仮面の使節 |
| 5 | 取引 | 情報や忠誠の見返りに保護を提示される |
| 6 | 支配 | 現地組織が黒冠宮の命令で動き始める |

### プロトタイプで出してよい匂わせ

| 匂わせ | 内容 | 直接説明しないこと |
|---|---|---|
| 無音地帯 | 森や廃砦の一角から音が消えている | 原因、術者、目的 |
| 黒い封蝋 | 王国文書に見慣れない黒い封が混じる | 誰が押したか |
| 異常な魔物 | 普通の魔物が規律ある動きをする | 支配者の正体 |
| 消えた足跡 | 途中で人や荷車の痕跡が消える | 転移や異界術の仕組み |
| 夢の文様 | 複数NPCが同じ紋様の悪夢を見る | 黒冠宮という名前 |
| 不自然な礼儀 | 敵対者が何かを恐れて丁寧に振る舞う | 何を恐れているか |

プロトタイプ内で「黒冠宮」という固有名は、原則として出さない。資料、噂、夢、痕跡から、プレイヤーが「背後に何かいる」と感じる程度に留める。

### 異界勢力との関係値

| 値 | 内容 |
|---|---|
| 認識度 | どれだけ存在を知られているか |
| 有用度 | 利用価値があると思われているか |
| 反抗度 | 敵対的と判断されているか |
| 汚染度 | 異界の品、契約、魔法に触れた度合い |

認識度が高いほどイベントは増えるが、安全ではない。有用度が高いと保護される可能性があるが、自由は減る。

## 4. 天賦のランダム付与方式

天賦は完全ランダムにすると、ロールプレイの芯が崩れる。

そのため、出自、血統、職業、初期選択によって候補を絞り、その中からランダムまたは選択式で付与する。

### 付与方式

| 方式 | 内容 | 向いている遊び |
|---|---|---|
| 完全選択 | プレイヤーが候補から1つ選ぶ | ロールプレイ重視 |
| 半ランダム | 出自ごとの3候補からランダム | 運命感と公平性 |
| 伏せランダム | 効果名を伏せて、イベントで判明 | 物語重視 |
| 後天覚醒 | 初期はなし。危機で発現 | ドラマ重視 |

最初のプロトタイプでは、半ランダムを基本にする。開始時に「天賦の兆し」だけ表示し、1日目の危機で正式名称が判明する。

### レア度抽選

| レア度 | 基本確率 | 備考 |
|---|---:|---|
| なし | 50% | 普通の現地人として始まる |
| 微光 | 30% | 小さな個性 |
| 希少 | 15% | はっきり有利 |
| 英雄 | 4% | 物語が大きく変わる |
| 伝説 | 0.8% | 専用イベント必須 |
| 異端 | 0.2% | 黒冠宮や神殿が反応する |

ゲーム開始時のオプションで「天賦あり」を選んだ場合は、なしを除外して再抽選する。

| 門番 | 鉄胃、低き者の顔 | 危機嗅覚、不信の祝福 | 一技模倣、魂の抵当 |
| 神殿雑用係 | 低き者の顔、鉄胃 | 祈りの残り火、王前沈黙 | 魔力残響視、不信の祝福 |

## 5. 1日ごとの進行システム

ゲームは1日を複数の時間帯に分け、行動、イベント、関係変化、資源消費を処理する。

最初のプロトタイプでは、5日間を1章とする。

### プレイヤー目的

プロトタイプの主目的は、黒幕の解明や大事件の解決ではなく、まず生きることに置く。

第一目標は食料の確保。次に、安全な寝床、信頼できる人間関係、逃走路、最低限の情報を確保する。プレイヤーは事件に巻き込まれるが、事件を追う義務はない。

| 優先度 | 目的 | 内容 |
|---:|---|---|
| 1 | 食料確保 | 自分と同行者が数日生きる食料を得る |
| 2 | 安全確保 | 寝床、避難場所、夜間の危険回避 |
| 3 | 関係確保 | 助けてくれるNPC、取引相手、所属先を作る |
| 4 | 情報確保 | 危険な場所、噂、魔物の動き、検問状況を知る |
| 5 | 選択肢確保 | 残留、逃亡、協力、抵抗、隠遁の道を残す |

プレイヤーは「異変を調べてもよい」が、「調べない自由」も持つ。調べない場合でも、世界の圧力は進行し、食料不足、魔物圧、検問、噂、NPCの行動によって別の物語が生まれる。

### 1日の構造

| 時間帯 | 主な行動 | 起きやすいこと |
|---|---|---|
| 朝 | 状況確認、噂、仕事の割り振り | ニュース、命令、NPC訪問 |
| 昼 | 主要行動 | 調査、治療、交渉、労働、移動 |
| 夕 | 人間関係 | 相談、密談、取引、祈り |

## 11. 死亡時の周回要素

主人公は現地人であり、死は軽くしない。

ただし、死亡で完全終了にすると試行錯誤が重くなりすぎるため、死亡時には「記録」「噂」「継承」「世界理解」が次周へ残る。これは主人公本人の転生ではなく、プレイヤーが世界を理解していくための周回要素として扱う。

### 基本方針

| 方針 | 内容 |
|---|---|
| 死亡は物語として残す | どこで、なぜ死んだかが記録される |
| 強さを直接持ち越しすぎない | 次の主人公も基本は弱い現地人 |
| 知識と選択肢を持ち越す | 危険な場所、NPCの裏事情、魔物の性質が分かる |
| レベルに応じて報酬を変える | 高Lvで死ぬほど、残せるものが増える |
| 死に方で解放内容を変える | 飢餓死、処刑、魔物死、異常接触で別の発見がある |

### 死亡時に記録されるもの

| 記録 | 内容 | 次周への影響 |
|---|---|---|
| 死因 | 飢餓、負傷、処刑、魔物、呪い、裏切りなど | 同種の危機に警告が出ることがある |
| 到達日数 | 何日生きたか | 初期情報や小さな補正 |
| 到達Lv | 死亡時の総合Lv | 継承点の基本値 |
| 職業履歴 | 伸ばした職業 | 次周の出自候補や初期職業候補 |
| 関係履歴 | 誰と信頼を築いたか | NPCの噂、初期好意、別視点イベント |
| 発見情報 | 魔物、場所、文書、異常 | 図鑑・地図・噂として残る |
| 所持品履歴 | 重要アイテムを持っていたか | 遺品、噂、商人の在庫に影響 |
| 天賦履歴 | 発現した天賦 | 次周で候補として出やすくなる |

### レベルに応じた継承

死亡時の総合Lvに応じて、次周へ残せるものが変わる。

| 死亡時Lv | 呼称 | 残せるもの |
|---:|---|---|
| 1-3 | 名もなき死 | 死因の記録、短い噂 |
| 4-7 | 小さな痕跡 | 死因警告、初期噂1つ |
| 8-12 | 町の記憶 | 地図断片、NPC情報、魔物情報1つ |
| 13-18 | 生還寸前の記録 | 出自候補追加、職業初期補正、重要NPCの初期認識 |
| 19-25 | 地方の逸話 | 天賦候補補正、特殊職の解放、遺品イベント |
| 26-35 | 英傑の死 | 新しい開始地点、勢力初期評価、固有イベント解放 |
| 36+ | 伝説の残響 | 世界設定の大きな開示、強力な周回特典 |

### 継承点

死亡時に「継承点」を得る。継承点は次周の初期設定に使う。

継承点の目安:

| 条件 | 継承点 |
|---|---:|
| 生存日数1日ごと | +1 |
| 総合Lv5ごと | +1 |
| 主要NPCの信頼を高めた | +1 |
| 魔物情報を記録した | +1 |
| 重要な場所を発見した | +1 |
| 天賦を発現した | +2 |
| 章結末に到達した | +3 |
| 異常接触を経験した | +3 |

### 継承点の使い道

| 使い道 | コスト | 効果 |
|---|---:|---|
| 初期食料 +1日分 | 1 | 序盤の自由度が上がる |
| 初期噂を1つ知る | 1 | 危険や機会を早く把握する |
| NPC初期好意 +1 | 1 | 指定NPCとの関係が少し良い |
| 地図断片を持つ | 2 | 特定地域の危険を知る |
| 職業経験の種 | 2 | 指定職業のLv成長が少し早い |
| 天賦候補を広げる | 3 | 高レア天賦候補が出やすくなる |
| 遺品の噂 | 3 | 前周の所持品がどこかに出る |
| 出自候補追加 | 4 | 新しい開始背景を選べる |
| 特殊職の兆し | 5 | 特殊職解放イベントが出やすい |

### 死に方による解放

| 死に方 | 解放されるもの |
|---|---|
| 飢餓死 | 食料警告、配給ルート、採集知識 |
| 魔物に殺される | その魔物の弱点情報、遭遇前兆 |
| 現地人に処刑される | 法制度、検問、役人の性格情報 |
| 裏切られて死ぬ | 該当NPCの危機条件、疑念警告 |
| 神殿で異端死 | 神殿派閥、異端審査条件 |
| 召喚事故死 | 契約文の危険箇所、召喚候補の警告 |
| 異常接触で消える | 無音地帯、黒い封蝋、夢の文様などの情報 |

### 遺品

死亡時、重要アイテムや所持品の一部は「遺品」として世界に残ることがある。

遺品は次周で必ず手に入るわけではない。噂、商人の在庫、魔物の巣、神殿の保管庫、処刑場の記録などに姿を変える。

| 遺品の行方 | 例 |
|---|---|
| 誰かが拾う | ミラが隠している、ガロが売っている |
| 組織に押収される | 守備隊倉庫、神殿記録室 |
| 魔物の巣に残る | 影豹の巣、灰狼の縄張り |
| 噂だけ残る | 「死んだ薬師が黒い鈴を持っていた」 |
| 汚染される | 元の効果とは違う異界品になる |

### 周回で避けたいこと

| 避けること | 理由 |
|---|---|
| ステータスを丸ごと持ち越す | 現地人としての弱さが消える |
| 死亡を軽くしすぎる | 食料や危険の緊張感がなくなる |
| 最適解を固定する | 自由生存型の面白さが減る |
| 高レア天賦を簡単に選ばせる | 世界の理不尽さと希少性が薄れる |

周回で強くなるのは、主人公そのものではなく、プレイヤーの知識、開始時の選択肢、世界に残る記録である。

### 周回成長

周回の面白さとして、死亡時Lvや生存時間に応じて、次周の能力を少しずつ上げられるようにする。

ただし、前周の主人公がそのまま転生して強くなるわけではない。  
これは「世界に残った記録」「噂」「遺品」「教訓」「プレイヤーの理解」が、次の現地人を少しだけ有利にする仕組みである。

### 成長資源

周回終了時に、以下の2種類の資源を得る。

| 資源 | 得られる条件 | 使い道 |
|---|---|---|
| 継承点 | 生存日数、到達Lv、結末、発見 | 初期食料、噂、NPC好意、地図断片など |
| 記憶片 | 死因、魔物遭遇、異常接触、重要NPC関係 | 能力補正、判定補正、天賦候補、特殊イベント解放 |

継承点は実用的な支援。  
記憶片は、より長期的な成長や解放に使う。

### 生存時間による報酬

| 生存時間 | 報酬 |
|---|---|
| 1日未満 | 死因記録のみ |
| 1日生存 | 継承点+1、初期噂候補 |
| 2日生存 | 継承点+2、地図断片候補 |
| 3日生存 | 継承点+3、記憶片+1、結末記録 |
| 3日生存かつ良結末 | 継承点+4、記憶片+2、開始時選択肢追加 |

3日プロトタイプでは、3日生存が最初の大きな達成になる。

### 到達Lvによる報酬

| 到達Lv | 報酬 |
|---:|---|
| 1-3 | 継承点+0、死因記録 |
| 4-7 | 継承点+1、関連行動の警告表示 |
| 8-12 | 継承点+2、関連職業の経験補正候補 |
| 13-18 | 継承点+3、初期カードの再抽選権1回 |
| 19-25 | 継承点+4、特殊職や高レア天賦候補の解放 |
| 26+ | 継承点+5、開始地点や勢力初期評価の解放 |

到達Lvが高いほど、次周の「作れる現地人」の幅が広がる。

### 周回で上げられる能力

周回成長では、直接Lvを持ち越さない。代わりに、以下の能力を小さく上げる。

| 能力 | 効果 | 上限 |
|---|---|---:|
| 生存知識 | 採集、食料管理、飢餓判定に補正 | +3 |
| 魔物知識 | 魔物観察、逃走、弱点看破に補正 | +3 |
| 交渉勘 | 取引、仲裁、説得に補正 | +3 |
| 隠密慣れ | 盗み、潜入、夜行動に補正 | +3 |
| 信仰理解 | 神殿、死霊、儀式への対応に補正 | +3 |
| 異常耐性 | 無音地帯、黒い封蝋、異界品への精神抵抗 | +3 |

各能力は最大+3まで。  
これ以上強くすると、現地人としての脆さが薄くなる。

### 記憶片の使い道

| 使い道 | コスト | 効果 |
|---|---:|---|
| 生存知識+1 | 1 | 食料関連判定に+1 |
| 魔物知識+1 | 1 | 魔物観察・逃走に+1 |
| 交渉勘+1 | 1 | NPC交渉や配給争いに+1 |
| 隠密慣れ+1 | 1 | 夜行動や盗みに+1 |
| 信仰理解+1 | 1 | 神殿・死霊イベントに+1 |
| 異常耐性+1 | 2 | 異常接触時の精神減少を軽減 |
| 前周の遺品候補 | 2 | 前周の重要アイテムが噂や倉庫に出る |
| 天賦候補拡張 | 3 | 高レア天賦の候補を1つ追加 |
| 出自候補解放 | 3 | 新しい出自を選べる |
| 特殊職の兆し | 4 | 特殊職イベントが出やすくなる |

### 死に方と能力成長

死因によって、得やすい記憶片や成長候補が変わる。

| 死に方 | 得やすい成長 |
|---|---|
| 飢餓死 | 生存知識、食料警告 |
| 魔物死 | 魔物知識、逃走補正 |
| 処刑 | 交渉勘、法制度の噂 |
| 裏切り | 交渉勘、NPC危機警告 |
| 盗み失敗 | 隠密慣れ、検問情報 |
| 神殿で異端死 | 信仰理解、異端審査条件 |
| 異常接触 | 異常耐性、黒い封蝋や無音地帯の記録 |

失敗したからこそ、次周で同じ危機に少しだけ強くなる。

### 周回開始時の表示

新しい周回を始める時、前周の成果を短く表示する。

```text
前回の記録:
2日目 夜、灰狼の群れにより死亡。

残ったもの:
魔物知識の記憶片 +1
灰狼の夜襲の警告
黒森外縁の地図断片
```

### 周回成長で守ること

| 方針 | 内容 |
|---|---|
| 強くなりすぎない | 能力補正は最大+3まで |
| 死を軽くしない | 死亡時の記録文と喪失感を残す |
| 知識を報酬にする | 何が危険か分かることを強みにする |
| 選択肢を増やす | 数値だけでなく、初期ルートや会話を増やす |
| 高レア天賦は希少にする | 解放されても簡単には選べない |

## 12. 関係性の深掘り

人間関係は、好意や信頼だけでは表せない。

この世界では、食料、安全、身分、魔法、恐怖、恩義によって、人と人の関係が非対称になる。主従、服従、恋人、庇護、依存、秘密共有は、プレイヤーの自由と生存を同時に変える。

### 関係性の基本軸

| 軸 | 内容 |
|---|---|
| 好意 | 相手を好きか |
| 信頼 | 約束を守ると思うか |
| 利害 | 得になる関係か |
| 恐怖 | 逆らうと危険だと思うか |
| 依存 | 相手なしでは生きづらいか |
| 所有感 | 相手を自分のものだと思っているか |
| 忠誠 | 損をしても従う気があるか |
| 情欲 | 恋愛・肉体的な惹かれ |
| 尊敬 | 相手の能力や人格を認めているか |
| 負債 | 恩や借りがあるか |

関係性は、これらの軸の組み合わせで決まる。恋人でも信頼が低いことがある。主従でも好意が高いことがある。服従でも忠誠がないことがある。

### 関係タイプ

| 関係 | 主な軸 | 得られるもの | 危険 |
|---|---|---|---|
| 友人 | 好意、信頼 | 無償の助け、精神回復 | 情に流される |
| 恋人 | 好意、情欲、信頼 | 強い支援、孤独耐性、専用会話 | 嫉妬、人質化、別離の傷 |
| 家族的庇護 | 好意、依存、負債 | 食料、寝床、看病 | 自由が減る、期待が重い |
| 主従 | 忠誠、立場、負債 | 命令、保護、役割分担 | 失敗時の責任、上下関係の固定 |
| 服従 | 恐怖、依存、所有感 | 即時の安全、命令による保護 | 自由喪失、裏切り衝動 |
| 師弟 | 尊敬、信頼、負債 | 技能成長、知識、紹介 | 師の敵や義務を継ぐ |
| 秘密共有 | 信頼、疑念、負債 | 危険情報、共犯関係 | 片方が崩れると両方破滅 |
| 契約関係 | 利害、義務、文書 | 明確な条件、報酬 | 契約穴、違約の罰 |
| 共依存 | 依存、好意、恐怖 | 強い結束、離脱困難 | 判断が歪む |
| 支配者と所有物 | 所有感、恐怖、利害 | 強い保護、資源 | 人格や選択を奪われる |

### 主従

主従は、上下関係が明確な協力関係。

主人公が従者になる場合も、誰かを従者にする場合もある。ただし現地人主人公が強大な主になるのは序盤では難しい。多くの場合、食料、安全、身分保証のために誰かの下に入る形になる。

| 形 | 内容 | 例 |
|---|---|---|
| 雇用主と従者 | 食料や金のために仕える | 商人の荷運び、貴族家の使用人 |
| 軍の上下 | 命令系統で動く | 門番、伝令、徴用兵 |
| 神殿奉仕 | 信仰と保護の代わりに奉仕する | 雑用係、看病、葬儀補助 |
| 師弟主従 | 技術と保護の代わりに雑務をする | 薬師の弟子、魔術師の助手 |
| 異常な主従 | 魔法、契約、恐怖で結ばれる | 召喚存在、異界品、呪い |

#### 主従の値

| 値 | 内容 | 高いと |
|---|---|---|
| 忠誠 | 主に従う意思 | 危険な命令にも従う |
| 保護 | 主が従者を守る意思 | 食料、寝床、身分保証を得る |
| 命令権 | 主が従者に命令できる強さ | 自由行動が制限される |
| 面子 | 主従関係の社会的な見え方 | 裏切りや失敗が大事になる |

### 服従

服従は、信頼や忠誠ではなく、恐怖・依存・契約・飢えによって従う状態。

服従は強い保護を生むことがあるが、プレイヤーの自由を大きく奪う。ゲーム上は救済でもあり、危険な罠でもある。

| 服従の理由 | 内容 |
|---|---|
| 飢え | 食料を得るために従う |
| 恐怖 | 殺されないために従う |
| 借金 | 負債を返すまで逆らえない |
| 弱み | 秘密を握られている |
| 魔法 | 魅了、契約、呪い |
| 恩義 | 命を救われ、逆らえない |

#### 服従状態の効果

| 効果 | 内容 |
|---|---|
| 安全の確保 | 主や支配者の庇護で当面は生きられる |
| 食料の安定 | 配給や寝床を得る |
| 行動制限 | 行ける場所、会える相手、話せる内容が制限される |
| 疑念の変化 | 支配者側からは信用され、他勢力からは疑われる |
| 反抗ゲージ | 屈辱、恐怖、友情で反抗の機会が生まれる |

### 恋人

恋人関係は、単なる好感度報酬ではなく、生存と危険を同時に増やす。

恋人は食料を分け、秘密を守り、負傷時に看病してくれる。一方で、人質、嫉妬、逃亡の足かせ、裏切りの痛みになる。

| 要素 | 内容 |
|---|---|
| 親密 | どれだけ心を許しているか |
| 信頼 | 秘密や計画を共有できるか |
| 情欲 | 恋愛的・肉体的に惹かれているか |
| 将来 | 一緒に逃げる、残る、家族を作るなどの願望 |
| 嫉妬 | 他NPCとの関係に反応する |
| 危機 | 恋人自身が食料、家族、身分で追い詰められているか |

#### 恋人イベント

| イベント | 選択 |
|---|---|
| 食料を半分くれる | 受け取る、断る、代わりに守る約束をする |
| 一緒に逃げたいと言う | 逃げる、待たせる、断る、別の安全策を探す |
| 秘密を打ち明ける | 信じる、疑う、利用する、守る |
| 他勢力に利用される | 救う、見捨てる、取引する、復讐する |
| 嫉妬する | 説明する、嘘をつく、距離を置く |
| 死別する | 遺品、復讐、精神崩壊、周回記録につながる |

### 関係性の変化

関係は固定されない。

| 変化 | 条件 |
|---|---|
| 友人から恋人へ | 好意、信頼、危機共有が高い |
| 恋人から共依存へ | 飢え、恐怖、孤立が続く |
| 主従から友人へ | 保護と尊重が積み重なる |
| 主従から服従へ | 命令権と恐怖が強くなりすぎる |
| 服従から反逆へ | 恐怖より怒りや希望が上回る |
| 秘密共有から裏切りへ | 危機が高く、信頼が低い |
| 契約から恋人へ | 利害関係の中で好意と信頼が育つ |

### 関係性と自由行動

関係性が深いほど、自由行動に影響する。

| 関係 | 追加される選択肢 | 失われる選択肢 |
|---|---|---|
| 恋人 | 一緒に逃げる、看病してもらう、秘密を共有する | 一人で逃げる選択が重くなる |
| 主従 | 主の命令で安全な仕事を得る | 命令に背くと疑念や処罰 |
| 服従 | 食料と寝床を得る | 夜行動や他勢力接触が制限 |
| 師弟 | 訓練や知識入手が増える | 師の頼みを断りにくい |
| 秘密共有 | 危険情報や隠しルートが出る | 裏切り時の被害が大きい |

### 関係性と死亡・周回

深い関係は死亡時にも残る。

| 関係 | 死亡時に残るもの |
|---|---|
| 恋人 | 遺品、手紙、次周での噂、別視点イベント |
| 主従 | 主の記録、従者の証言、勢力評価 |
| 服従 | 支配者の名、契約痕、反抗ルート |
| 師弟 | 技能の種、師の紹介状、未完の課題 |
| 秘密共有 | 隠し文書、共犯記録、裏切り警告 |

### 扱いの注意

| 注意 | 理由 |
|---|---|
| 恋人を単なる報酬にしない | 生存と選択の重さを持たせる |
| 服従を美化しすぎない | 自由喪失と恐怖を明確にする |
| 主従に相互責任を持たせる | 便利な命令システムだけにしない |
| 嫉妬を理不尽にしすぎない | プレイヤーの自由を不快に奪わない |
| 関係破綻にも物語を残す | 裏切りや別離も周回記録にする |

## 13. キャラメイク形式

キャラメイクは、最初から全項目を完全自由に選ばせない。

プレイヤーには `S / A / B / C / D / E` の6枚のカードを渡す。左に行くほど価値が高い。各カードは一度だけ使え、6つの項目すべてに1枚ずつ割り振る。

これにより、主人公は必ず長所と弱点を持つ。強い天賦を選ぶなら、職業や食料や立場が弱くなるかもしれない。高いレベル上限を選ぶなら、初期は貧しく孤立しているかもしれない。

この方式は「現地人としての不完全さ」を保ちながら、プレイヤーに自分の人生を組み立てる感覚を与える。

### 参考モデル

参考にするカード構造は、6枚のカードを6項目へ使い切る形式。

参考元の項目構成は、以下の6つ。

| 参考項目 | 本作での解釈 |
|---|---|
| 限界レベル | レベル上限、器量上限 |
| 出身 | 職業、階級、血統、種族、育った共同体 |
| 能力値 | 素の才能、成長効率、基礎能力補正 |
| 特殊アイテム | 初期アイテム、遺物、借金や装備不足 |
| タレント | 天賦 |
| コネクション | 初期立場、庇護者、主従、恋人、所属 |

本作では、出身をより細かく扱いたいため、プロトタイプでは `職業` と `血統・種族` を分けてもよい。ただし、カード枚数と選択項目数は必ず一致させる。

### 推奨カード項目

最初に実装するなら、参考モデルに近い6項目版を推奨する。

| 番号 | 項目 | 意味 | 主に決まるもの |
|---:|---|---|---|
| 1 | レベル上限 | どこまで伸びる器か | 器量上限、成長余地、将来の影響力 |
| 2 | 出身 | どこで、何者として生まれ育ったか | 職業、階級、血統・種族、初期社会 |
| 3 | 能力値 | 素の才能の高さ | 基礎能力、成長効率、判定補正 |
| 4 | 特殊アイテム | 何を持っているか、または何を欠いているか | 食料、武具、遺物、借金 |
| 5 | 天賦 | 生まれ持った異能 | 特殊能力、希少度、危険度 |
| 6 | コネクション | 誰とつながっているか | 庇護者、所属、恋人、主従、敵対者 |

拡張版では、出身を `職業` と `血統・種族` に分割し、初期立場や初期関係も独立させる。

### 拡張版の基本選択

出身を細かく扱う場合は、以下の6項目にカードを割り振る。

| 番号 | 項目 | 意味 | 主に決まるもの |
|---:|---|---|---|
| 1 | 職業 | 何をして生きてきたか | 初期職業Lv、技能、所属、働き口 |
| 2 | 血統・種族 | 何として生まれたか | 種族特性、社会的扱い、適性 |
| 3 | 天賦 | 何を生まれ持ったか | 特殊能力、希少度、危険度 |
| 4 | レベル上限 | どこまで伸びる器か | 器量上限、成長余地 |
| 5 | 初期アイテム | 何を持っているか | 食料、道具、武具、遺物、禁制品 |
| 6 | 初期立場 | 誰に守られ、誰に疑われるか | 勢力関係、身分、配給、検問 |

プレイヤーは、各項目に `S / A / B / C / D / E` を1枚ずつ割り振る。

この拡張版では、参考モデルの `能力値` は `レベル上限` と各判定補正に統合して扱う。より原型に近づけたい場合は、`初期立場` を `能力値` に差し替え、立場は `コネクション` へ統合する。

例:

| 項目 | カード |
|---|---|
| 職業 | B |
| 血統・種族 | D |
| 天賦 | S |
| レベル上限 | C |
| 初期アイテム | E |
| 初期立場 | A |

この場合、主人公は強力な天賦と良い立場を持つが、血統は平凡寄りで、初期アイテムは貧弱になる。

### カード価値

| カード | 価値 | 意味 |
|---|---|---|
| S | 最高 | その項目が人生を変えるほど強い |
| A | 高い | 明確な長所になる |
| B | やや高い | 安定した強み |
| C | 普通 | 平均的。大きな不利はない |
| D | 低い | 弱点になりやすい |
| E | 最低 | かなり苦しい。不利な物語が生まれる |

Sカードは強いが、必ずしも安全ではない。天賦S、血統S、アイテムSは、強力であるほど周囲に狙われる。

### 能力値カード

参考モデルに近い6項目版を使う場合、能力値カードは素の才能を表す。

| カード | 能力値状態 | 効果 |
|---|---|---|
| S | 天才 | 判定補正が大きい。格上を一瞬驚かせる |
| A | 秀才 | 成長と判定に明確な補正 |
| B | 才人 | 一部の能力が伸びやすい |
| C | 平凡 | 補正なし |
| D | 鈍才 | 成長や判定に小さな不利 |
| E | 不器用 | 生存には別の強みが必要 |

能力値カードはレベル上限を直接変えない。高い能力値は、同レベル帯での判定、成長速度、格上への一時的な対抗に影響する。

### コネクションカード

参考モデルに近い6項目版を使う場合、コネクションカードは初期立場と初期関係をまとめて扱う。

| カード | コネクション状態 | 初期例 |
|---|---|---|
| S | 強力な庇護者 | 貴族、神殿上層、守備隊幹部、危険な主 |
| A | 安定した所属 | 商人組合、神殿、村の有力者 |
| B | 使える縁 | 友人、師匠、恋人、下級兵士 |
| C | 薄い縁 | 顔見知り、近所、日雇い先 |
| D | 孤立気味 | 頼れる相手が少ない |
| E | 悪い縁 | 借金取り、敵対者、支配者、危険な主従 |

コネクションSは安全とは限らない。強い庇護者は、強い命令権や所有感を持つことがある。

### カード割り振りの設計意図

| 割り振り | プレイ感 |
|---|---|
| 職業S | 生活力が高く、食料確保が得意 |
| 血統S | 生まれの力が強いが、社会的な目も強い |
| 天賦S | 理不尽な切り札を持つが、危険人物になる |
| レベル上限S | 今は弱くても長期的に化ける |
| 初期アイテムS | 序盤から強い物を持つが、狙われる |
| 初期立場S | 保護や配給が強いが、組織に縛られる |

低いカードを置いた項目は、単なる罰ではなく、物語の火種になる。

| 低カード項目 | 生まれる物語 |
|---|---|
| 職業E | 食べる手段がなく、労働や盗みに追われる |
| 血統E | 差別、病弱、身元不明などの不利 |
| 天賦E | 天賦なし、または扱いにくい微弱能力 |
| レベル上限E | 成長の限界が早い |
| 初期アイテムE | ほぼ手ぶらで始まる |
| 初期立場E | 無所属、疑われている、追われている |

### 1. 職業カード

職業カードは、主人公がどれだけ「働いて食べられるか」を決める。

| カード | 職業状態 | 初期例 |
|---|---|---|
| S | 上位職または複合職 | 薬師Lv4 / 書記Lv2、狩人Lv4 / 魔物知識Lv2 |
| A | 明確な専門職 | 薬師Lv3、兵士Lv3、書記Lv3 |
| B | 実用職 | 農民Lv3、狩人Lv2、神官見習いLv2 |
| C | 見習い職 | 使用人Lv2、民兵Lv1、荷運びLv2 |
| D | 不安定な職 | 日雇い、使い走り、半端な徒弟 |
| E | 職なし | 流民、避難民、追放者、病み上がり |

職業カードが高いほど、昼行動で食料を得やすい。低いほど、配給、盗み、誰かへの依存が重要になる。

### 2. 血統・種族カード

血統・種族カードは、生まれの強さと社会的リスクを決める。

| カード | 血統状態 | 初期例 |
|---|---|---|
| S | 強力な血統、先祖返り | 古代血統、異界混入、濃い魔性血統 |
| A | 明確な特殊血統 | 聖別血統、魔性血統、森民の濃血 |
| B | 有用な薄血 | 亜人薄血、地底民血統、森民混血 |
| C | 一般的な人間 | 差別は少ないが特別な保護もない |
| D | 不利な出自 | 被差別血統、身元不明、病弱な家系 |
| E | 危険な血統 | 異端疑惑、呪血、追放された家系 |

血統カードが高いほど適性は強いが、発覚時の政治的・宗教的リスクも上がる。

### 3. 天賦カード

天賦カードは、生まれ持った特殊能力の希少度を決める。

| カード | 天賦状態 | 初期例 |
|---|---|---|
| S | 異端または伝説 | 魔法断絶域、無作為宝庫、魔喰いの拒絶 |
| A | 伝説または英雄 | 異位階放射、王命の声、死線の帳簿 |
| B | 英雄 | 魔力残響視、一技模倣、獣王の息 |
| C | 希少 | 危機嗅覚、祈りの残り火、王前沈黙 |
| D | 微光 | 鉄胃、低き者の顔、道具耳 |
| E | なし、または不便な天賦 | 天賦なし、嘘がつけない、悪夢を見る |

天賦カードが高いほど、格上への逆転手段が生まれる。代わりに、疑念、汚染度、認識度が上がりやすい。

### 4. レベル上限カード

レベル上限カードは、主人公の器量上限を決める。

| カード | 器量 | 総合Lv上限 | 特徴 |
|---|---|---:|---|
| S | 英雄器、まれに神話器 | 35-50 | 将来性が異常。序盤は狙われやすい |
| A | 逸材 | 25 | 国家や組織が欲しがる |
| B | 才人 | 18 | 地方で名が通る可能性 |
| C | 有望 | 12 | 村や町で優秀 |
| D | 平凡 | 8 | 普通の現地人 |
| E | 低器量 | 5 | 成長限界が早い。別の強みが必要 |

レベル上限カードが高いほど、長期的には強い。短期的な食料確保には直結しない。

### 5. 初期アイテムカード

初期アイテムカードは、持ち物による序盤の有利不利を決める。

| カード | 初期アイテム状態 | 初期例 |

| A | 明確な有用品 | 保存食5日分、薬箱、通行証、良武具 |
| B | 実用品 | 保存食3日分、短剣、道具一式 |
| C | 最低限 | 保存食1日分、粗末な道具 |

| E | ほぼ手ぶら | 食料なし、所持金なし、服だけ |

アイテムカードが高いほど序盤は安定するが、盗難、押収、疑念の対象になりやすい。

### 6. 初期立場カード

初期立場カードは、どの勢力に守られ、どの勢力に疑われるかを決める。

| カード | 初期立場状態 | 初期例 |

| S | 強い保護や身分 | 貴族筋の庇護、神殿の正式保護、守備隊所属 |
| A | 安定した所属 | 村の有力者の身内、商人組合の下働き |
| B | 弱いが使える所属 | 神殿雑用、冒険者見習い、門番補助 |
| C | 一般民 | 村人、町人、日雇い |
| D | 無所属 | 難民、流民、身元不明 |
| E | 危険な立場 | 追放者、検問対象、異端疑惑、借金持ち |

立場カードが高いほど配給や保護を得やすい。低いほど自由だが、生存の保証がない。

### 7. 初期関係カード

初期関係を選べるようにする場合、主人公は最初から誰かとの強い縁を持つ。

| 関係 | 初期効果 | 危険 |
|---|---|---|
| 友人 | 相談相手、精神安定 | 頼られる |
| 恋人 | 食料共有、秘密共有 | 人質化、嫉妬、逃亡の重さ |

| 秘密共有 | 危険情報 | 裏切り時の被害が大きい |

### 8. 初期リスクカード

初期リスクを選べるようにする場合、主人公は強い問題を抱えた状態で始まる。

| リスク | 効果 |
|---|---|
| 借金 | 裏市や商人に追われるが、裏社会ルートが開く |
| 病人の同行者 | 食料消費が増えるが、関係ドラマが強い |
| 検問対象 | 都市移動が難しいが、逃亡プレイが濃くなる |
| 盗品所持 | 強い初期アイテムを持つが疑念が高い |
| 異端疑惑 | 神殿イベントが増える |
| 魔物の目撃者 | 魔物情報を持つが恐怖が高い |

### キャラメイクの推奨手順

最初のプロトタイプでは、以下の簡易手順にする。

1. `S / A / B / C / D / E` の6枚を表示する
2. 6項目にカードを1枚ずつ割り振る
3. 各項目の中身をカード価値に応じて抽選または選択する
4. 食料、立場、関係、リスクを短く提示する
5. 最後に「この人物で始める」か「割り振りをやり直す」を選ぶ

将来的に項目が8つに増えたら、カードも `S / A / B / C / D / E / F / G` のように増やす。項目数とカード枚数は必ず同じにする。

### 生成例

| 項目 | 内容 |
|---|---|
| 職業 | B: 森の狩人Lv2 |
| 血統・種族 | D: 平凡な人間だが身元が弱い |
| 天賦 | S: 魔喰いの拒絶 |
| レベル上限 | C: 有望、総合Lv上限12 |
| 初期アイテム | E: 食料なし、古い短刀だけ |
| 初期立場 | A: 灰麦村では信用がある |

この主人公は、普段はただの狩人に近い。村では信用があるが、食料を持たず、血統も特別ではない。その代わり、格上魔物の魔法を一度だけ拒絶できる。強いが、使った瞬間に「ただの現地人」ではいられなくなる。

## 14. カード割り振りによる人物テンプレート

カード割り振りは、主人公だけでなく、モブ、NPC、敵対者、恋人候補、主、従者、魔物使いなどを作る基準にも使う。

重要なのは、すべての人物を詳細に作り込むことではない。必要な人物だけカードを割り振り、その他のモブは簡易テンプレートで処理する。

### 人物作成の基準

| 人物種別 | カード割り振り | 用途 |
|---|---|---|
| 背景モブ | C/D/E中心 | 名前なし、短い会話だけ |
| 重要モブ | B/C/D/E中心 | 食料、噂、対立に関わる |
| 通常NPC | AからEを使用 | 関係値を持つ |
| 主要NPC | SからEを使用 | 物語や周回に残る |
| 強敵 | S/Aを複数持つ場合あり | 例外的に主人公より強い |
| 権力者 | 立場やコネクションが高い | 戦闘力より社会的圧力 |
| 天賦持ち | 天賦がA以上 | 目立つ、狙われる、保護される |

主人公は基本的に `S/A/B/C/D/E` を1枚ずつ使う。  
NPCは必ずしも同じ制限にしなくてよい。権力者や強敵は、世界の格差を表すためにSやAを複数持っていてもよい。

### 参考用の6項目

人物テンプレートでは、以下の6項目を使う。

| 項目 | 内容 |
|---|---|
| レベル上限 | 将来的にどこまで強くなれるか |
| 出身 | 職業、階級、血統、種族、育ち |
| 能力値 | 素の才能、判定補正、成長効率 |
| 特殊アイテム | 持ち物、装備、遺物、借金 |
| 天賦 | 生まれつきの異能 |
| コネクション | 立場、所属、人間関係、庇護者 |

## 16. モブ運用ルール

### モブの強さは一項目で決めない

レベル上限が低くても、特殊アイテムやコネクションが高い人物は危険。  
逆に、天賦が高くても食料や立場が弱ければ、すぐ利用される。

### モブの役割

| 役割 | 必要な高カード |
|---|---|
| 食料を握る | 特殊アイテム、コネクション、出身 |
| 情報を握る | 出身、能力値、コネクション |
| 戦える | レベル上限、出身、能力値 |
| 利用される | 天賦、特殊アイテムが高く、コネクションが低い |
| 支配する | コネクション、出身、特殊アイテム |
| 裏切る | 能力値、コネクション、食料危機 |

### 主人公との比較

主人公はカードを1枚ずつ公平に割り振る。  
世界の住人は必ずしも公平ではない。

貴族はコネクションSと出身Sを持つかもしれない。  
奴隷は出身EとコネクションEを背負うかもしれない。  
天賦持ちの孤児は天賦Aでも、他がほぼEかもしれない。

この不公平さが、現地人世界の階級差と理不尽さになる。

## 17. 3日間プロトタイプ仕様

最初のプレイ可能版は、3日間だけを扱う。

目的は、大きな物語を完結させることではなく、以下を確認すること。

- 食料を確保する緊張感があるか
- 自由行動が意味を持つか
- NPCとの関係が選択に影響するか
- 魔物や現地人との対立が発生するか
- 黒幕を直接出さずに、不穏な匂わせができるか
- 死亡や失敗が次に活かせる形になっているか

### プロトタイプの勝利条件

| 条件 | 内容 |
|---|---|
| 生存 | 3日目の夜を越える |
| 食料 | 最終時点で食料0でもよいが、飢餓崩壊していない |
| 関係 | 少なくとも1人のNPCとの関係が変化している |
| 記録 | 1つ以上の噂、魔物情報、異常痕跡を得ている |

勝利は「世界を救う」ことではない。  
3日間を生き延び、自分なりの居場所や次の道を残せれば成功。

### プロトタイプの失敗条件

| 条件 | 内容 |
|---|---|
| 死亡 | 体力が0になり、救助もない |
| 飢餓崩壊 | 食料不足で体力・精神が崩れ、行動不能になる |
| 捕縛 | 守備隊、神殿、裏市などに拘束される |
| 追放 | 主要拠点から追い出され、寝床と食料を失う |
| 精神崩壊 | 恐怖や罪悪感で選択肢が極端に狭まる |

失敗しても、死因や得た情報は周回記録に残る。

### 3日間の構成

| 日 | 目的 | 主な圧力 | 確認したい体験 |
|---:|---|---|---|
| 1 | 今日食べる | 食料不足、出自別事件 | 自由行動と初期NPC関係 |
| 2 | 明日の安全を作る | 魔物圧、疑念、食料圧 | 対立、取引、隠蔽 |
| 3 | 次の道を選ぶ | 検問、魔物接近、異常痕跡 | 結末分岐と周回記録 |

## 20. セーブ仕様

3日間プロトタイプでは、1日単位のオートセーブを採用する。

いつでも手動セーブできる形式にはしない。選択の緊張感を保つため、保存されるのは1日の終了時だけにする。

### 基本方針

| 項目 | 内容 |
|---|---|
| セーブ方式 | 1日終了時の自動保存 |
| セーブ枠 | 1枠 |
| 保存タイミング | 夜行動と強制イベントの処理後 |
| ロード位置 | 翌日の朝 |
| 手動セーブ | なし |
| 戦闘中セーブ | なし |
| 選択肢直前セーブ | なし |
| 新規開始 | 既存セーブを上書きするか確認 |

### セーブ演出

保存時には、ゲーム内で短い記録文を表示する。

例:

```text
夜が明ける。
あなたの今日の選択は、灰境地方のどこかに小さな痕跡を残した。
記録を保存しました。
```

死亡時は通常セーブではなく、死亡記録として保存する。

例:

```text
あなたの足跡は、黒森の入口で途切れていた。
死因: 灰狼の群れ
周回記録に「灰狼の夜襲」が追加されました。
```

### 保存するデータ

| データ | 内容 |
|---|---|
| 進行 | 日数、時間帯、現在地 |
| キャラメイク | カード割り振り、出身、天賦、上限、アイテム、コネクション |
| リソース | 体力、精神、食料、物資 |
| 状態圧 | 食料圧、魔物圧、疑念、認識度 |
| NPC | 関係値、危機、発生済みイベント |
| 所持品 | 食料、道具、特殊アイテム、遺品候補 |
| 記録 | 噂、魔物情報、異常痕跡、地図断片 |
| フラグ | 昼行動、夜行動、解決済み対立、結末候補 |
| 周回 | 死因記録、解放情報、継承点 |

### ロード時の扱い

ロードすると、保存された翌朝から再開する。

| 状況 | ロード後 |
|---|---|
| 1日目終了セーブ | 2日目朝から再開 |
| 2日目終了セーブ | 3日目朝から再開 |
| 3日目終了 | 結末表示後、周回記録へ |
| 死亡記録 | 新規開始時に周回情報として参照 |

### ブラウザ版での実装

ブラウザプロトタイプでは、`localStorage` を使う。

| キー | 内容 |
|---|---|
| `overlocal_save` | 現在の1日単位セーブ |
| `overlocal_meta` | 周回記録、解放情報 |

保存データはJSON形式にする。  
将来的にセーブスロットを増やす場合は、`overlocal_save_1`、`overlocal_save_2` のように拡張する。

### セーブで避けたいこと

| 避けること | 理由 |
|---|---|
| 選択肢ごとの巻き戻し | 食料や人間関係の重さが消える |
| 戦闘前セーブ | 危険行動の緊張感が消える |
| 死亡直前ロード | 周回要素の意味が薄れる |
| セーブ枠を増やしすぎる | プロトタイプ検証が散らばる |

## 21. UI・文体・判定方式

プロトタイプは、ブラウザで動くテキストRPG形式にする。

ゲームの中心は、記録を読み、状態を確認し、選択肢を選び、ダイス判定によって結果を受け入れること。

### 文体

文体は記録調にする。

主人公の感情を断定しすぎず、観察、行動、結果を淡々と記す。  
ただし、冷たすぎないように、食料、寒さ、沈黙、視線、疲労などの具体的な描写で緊張感を出す。

| 方針 | 内容 |
|---|---|
| 一人称は使わない | 主人公をプレイヤーの器にする |
| 基本は二人称 | 「あなたは」で記録する |
| 感情は断定しすぎない | 「恐怖した」より「手が震えた」 |
| 情報は記録風に整理する | 重要な変化はログとして残す |
| 黒幕は説明しない | 異常は観測結果だけを書く |

例:

```text
1日目 朝 灰麦村

倉の麦袋は、昨日より三つ減っていた。
村長は都市ヴェルツへの供出を命じた。
ミラは井戸のそばに立ち、あなたを見ていた。

記録:
食料圧が1上昇した。
ミラが会話を求めている。
```

### キャラメイクUI

カード割り振りUIはクリック式にする。

ドラッグ式は使わない。プロトタイプでは、操作の分かりやすさと実装の安定性を優先する。

#### 操作手順

1. `S / A / B / C / D / E` のカードを表示する
2. プレイヤーがカードをクリックする
3. 割り振り先の項目をクリックする
4. その項目にカードが設定される
5. 使用済みカードは暗く表示され、再使用できない
6. 項目をクリックすると、割り振りを解除してカードを戻せる
7. 全項目にカードを置いたら「生成する」を押せる

#### 表示例

```text
カード:
[S] [A] [B] [C] [D] [E]

割り振り:
レベル上限     未設定
出身           未設定
能力値         未設定
特殊アイテム   未設定
天賦           未設定
コネクション   未設定
```

### 主人公入力

主人公は、名前を自由入力できる。

性別は以下の3つから選ぶ。

| 選択 | 内容 |
|---|---|
| 男性 | 男性として扱われる |
| 女性 | 女性として扱われる |
| 不詳 | 性別を明示しない |

性別は、恋人、主従、婚姻、身分、噂に影響する可能性がある。  
ただし、プロトタイプでは大きな能力差は付けない。テキスト差分と一部NPC反応に留める。

名前未入力の場合は `名もなき現地人` とする。

### 判定方式

判定はTRPG風のダイス式にする。

基本は `1d20 + 補正 >= 難易度` で判定する。

| 要素 | 内容 |
|---|---|
| ダイス | 1d20 |
| 補正 | 能力、職業、アイテム、関係、状況 |
| 難易度 | 行動の危険度 |
| 成功 | 目的を達成 |
| 失敗 | 代償、悪化、別イベント |

### 難易度

| 難易度 | 目安 | 例 |
|---:|---|---|
| 6 | 簡単 | 村で聞き込み、軽作業 |
| 9 | 普通 | 採集、説得、軽い治療 |
| 12 | 難しい | 夜の偵察、検問突破、盗み |
| 15 | 危険 | 魔物との交渉、証拠隠蔽 |
| 18 | 非常に危険 | 格上魔物から逃げる、神殿の追及をかわす |
| 21 | ほぼ無謀 | 異常現象への接触、強敵への対抗 |

### 補正

| 補正元 | 例 |
|---|---|
| 能力値カード | S:+4、A:+3、B:+2、C:+0、D:-1、E:-2 |
| 職業適性 | 関連職業Lvの一部を加算 |
| アイテム | 道具、武具、薬、通行証 |
| NPC関係 | 信頼が高いNPCの助力 |
| 状況 | 夜、飢餓、負傷、疑念、魔物圧 |
| 天賦 | 条件を満たすと大きな補正、または自動成功 |

### 判定結果

判定は成功/失敗だけでなく、差分で結果を変える。

| 結果 | 条件 | 内容 |
|---|---|---|
| 大成功 | 難易度+5以上 | 目的達成、追加利益 |
| 成功 | 難易度以上 | 目的達成 |
| 代償つき成功 | 難易度-2以内 | 目的達成。ただし体力、食料、疑念などに代償 |
| 失敗 | 難易度-3以下 | 目的失敗、不利な変化 |
| 大失敗 | 出目1、または難易度-8以下 | 負傷、捕縛、重大な関係悪化 |

自然20は原則として大成功。  
自然1は原則として大失敗。  
ただし、絶対に不可能な行動は自然20でも完全成功にはしない。

### 判定ログ

判定結果は記録調で表示する。

例:

```text
判定: 夜の偵察
1d20: 14
補正: 狩人 +2 / 夜間 -1
合計: 15
難易度: 12
結果: 成功

記録:
灰狼の足跡は、森から逃げるように村へ向かっていた。
魔物圧が1上昇した。
```

### ランダム性の扱い

すべてをランダムにしない。

| 処理 | 方針 |
|---|---|
| 昼行動 | 多くは判定あり |
| 夕イベント | 基本は固定結果。会話選択で変化 |
| 夜行動 | 判定あり。危険度が高い |
| 死亡判定 | 直前に救済条件を確認 |
| 天賦 | 一部は自動成功や振り直しを許す |
| 重要結末 | 条件判定を重視し、完全ランダムにしない |

### UI画面構成

プロトタイプは1画面完結にする。

| 位置 | 内容 |
|---|---|
| 左 | 主人公、カード割り振り、リソース |
| 中央 | 現在の記録文、選択肢 |
| 右 | NPC関係、噂、魔物情報、ログ |
| 下 | 判定ログ、保存表示 |

スマートフォンでは、縦並びにする。

1. 状態
2. 記録文
3. 選択肢
4. NPC/噂
5. 判定ログ

### 魔物戦闘画面

魔物との遭遇時は、通常の選択肢画面ではなく、簡易戦闘画面を表示する。

戦闘画面では、敵の脅威度、分類、耐久、魔法・能力、弱点、観測記録を表示する。あわせて、主人公の天賦と使用可能な簡易魔法も表示する。

| 表示 | 内容 |
|---|---|
| 魔物名 | 灰狼、墓灯り、小鬼の斥候、影豹の気配など |
| 脅威度 | D、C、Bなど |
| 分類 | 獣型、死霊型、亜人型、魔獣型 |
| 耐久 | 戦闘上の粘り強さ |
| 魔法・能力 | 影渡り、灯誘い、煙玉など |
| 弱点 | 火、祈り、交渉、逃走など |
| 天賦 | 現在の主人公が持つ天賦の戦闘効果 |
| 魔法 | 火種、傷塞ぎ、獣縛りなど |

### 戦闘行動

| 行動 | 内容 |
|---|---|
| 観察する | 弱点や能力を記録する |
| 武器で対処する | 相手を退ける。失敗時は負傷しやすい |
| 魔法を使う | 物資を消費し、火種や獣縛りで距離を作る |
| 天賦を使う | 天賦ごとの特殊効果で状況を変える |
| 逃走する | 倒さず離脱する |

戦闘の成功条件は、必ずしも討伐ではない。  
情報を得る、被害を抑える、逃げる、天賦の危険性を記録することも成功とする。

## 22. NPC行動と履歴

NPCは、プレイヤーが話しかけるまで停止している存在ではない。

各NPCは毎日、自分の目的、危機、所属、食料状況に応じて行動する。プレイヤーが関わらなくても、NPC同士の関係や地域状況は少しずつ変化する。

### NPC行動の目的

| 目的 | 内容 |
|---|---|
| 生存 | 食料、寝床、安全を確保する |
| 保護 | 家族、恋人、部下、信徒を守る |
| 利益 | 食料、金、情報、地位を得る |
| 義務 | 所属組織の命令を果たす |
| 秘密 | 隠し事や罪を守る |
| 調査 | 異常、魔物、文書、噂を追う |
| 裏切り | 自分や大切な人を守るため他者を売る |

### NPCの毎日行動

1日の終了時、主要NPCごとに簡易行動を処理する。

| 状態 | NPCが取りやすい行動 |
|---|---|
| 食料不足 | 食料を探す、盗む、頼る、裏市へ行く |
| 信頼が高い | プレイヤーへ情報や助力を持ってくる |
| 疑念が高い | プレイヤーを避ける、報告する、試す |
| 危機が高い | 裏切り、逃亡、無謀な取引をする |
| 所属圧が高い | 命令に従い、個人的感情を抑える |
| 異常情報を持つ | 神殿、行政庁、裏市、プレイヤーの誰かへ渡そうとする |

### NPC履歴

NPCには履歴を持たせる。

履歴は、現在の関係値よりも重い意味を持つことがある。  
一度見捨てた、秘密を守った、食料を分けた、嘘をついた、という事実は後から戻ってくる。

| 履歴 | 後の影響 |
|---|---|
| 食料を分けた | 好意、信頼、恋人・友人ルート |
| 食料を断った | 危機上昇、別勢力へ頼る |
| 嘘をついた | 疑念履歴。露見時に大きく悪化 |
| 秘密を守った | 秘密共有、共犯関係 |
| 密告した | 立場上昇、好意低下、裏切り記録 |
| 助けなかった | 死亡、失踪、敵対化 |
| 一緒に逃げた | 強い関係化、他勢力から疑念 |

### NPCの履歴表示

UI上では、各NPCに短い履歴を表示する。

例:

```text
ミラ
関係: +2
危機: 1
履歴:
- 1日目夕、食料を分けた。
- 2日目朝、井戸端の噂を教えた。
```

### NPCごとの行動方針

| NPC | 平常時 | 危機時 | 高信頼時 |
|---|---|---|---|
| ミラ | 村の噂を集め、家族の食料を探す | 食料を盗むか、村外へ逃げようとする | 食料や村情報を共有する |
| ロアン | 検問勤務と守備隊の命令に従う | 上官へ報告し、プレイヤーを止める | 夜間通行や検問情報を融通する |
| セヴァン | 神殿記録を整理する | 異端審査から自分を守る | 黒い封蝋や遺体の記録を見せる |
| ガロ | 食料と禁制品を動かす | 借りを盾に服従を迫る | 裏道や逃走路を売る |
| シィル | 森の境界を監視する | 都市人を森から締め出す | 魔物の弱点や安全な獣道を教える |

### 歴史を作る

NPC履歴は、地域の歴史にもなる。

プレイヤーが3日間で行った選択は、次周や続きの章で以下のように残る。

| 履歴 | 地域への残り方 |
|---|---|
| 配給争いを仲裁した | 「あの時、暴動を止めた者」と噂される |
| 倉庫不正を暴いた | 商人組合の警戒が上がる |
| ミラを見捨てた | 村で冷たい噂が残る |
| ロアンに嘘をついた | 守備隊の記録に矛盾が残る |
| セヴァンと秘密を共有した | 神殿記録室に隠し文書が残る |
| ガロに借りを作った | 裏市の帳簿に名前が残る |
| シィルと森へ逃げた | 黒森の民に記憶される |

この履歴が、単なるエンディングではなく、次の周回・次章・NPCの態度を作る。

## 23. 歴史年表と国家イベント

主人公が生まれる年を `1000年` とする。

ゲーム世界は、主人公の行動とは別に歴史を進める。国は戦争し、飢饉に苦しみ、王が死に、神殿が派閥争いを起こし、商人が価格を吊り上げ、魔物の大移動が起こる。

主人公はただの現地人なので、すべての歴史を動かすことはできない。
しかし、情報を届ける、誰かを助ける、食料を守る、密告する、逃げ道を作る、証拠を隠すといった行動で、小さな歴史の分岐を作れる。

### 歴史の基本単位

| 単位 | 内容 | 例 |
|---|---|---|
| 日 | プロトタイプ内の行動単位 | 食料、NPC、魔物遭遇 |
| 月 | 地方の情勢変化 | 配給不足、検問強化、疫病 |
| 年 | 国家イベント | 王の死、戦争、条約、粛清 |
| 世代 | 周回や大きな章の単位 | 前主人公の噂、遺品、地方伝承 |

3日間プロトタイプでは日単位だけを扱う。
将来的な本編では、章ごとに月単位・年単位の歴史イベントを処理する。

### 主要国家

| 国・勢力 | 概要 | 主な問題 | プレイヤーが関われる形 |
|---|---|---|---|
| ヴェルツ辺境領 | 灰境地方を含む王国辺境 | 食料不足、魔物、検問 | 村、守備隊、神殿、商人を通じて関与 |
| 王都中央 | 王国の中枢 | 王権低下、貴族対立、情報封鎖 | 文書、使者、徴発命令として影響が届く |
| 東方連邦 | 複数都市の商業連合 | 交易路、価格操作、傭兵 | 商人組合、密輸、食料価格に影響 |
| 北方部族圏 | 亜人・森民・遊牧民の連合圏 | 国境摩擦、魔物移動、差別 | 黒森の民や難民を通じて接触 |
| 白燭教圏 | 神殿ネットワーク | 異端審査、治癒独占、死霊対策 | 神殿保護、異端疑惑、葬儀記録 |
| 地底鉱山都市群 | 鉱山と職人氏族の都市 | 資源枯渇、遺物発掘、技術流出 | 鉱山跡、遺物、鍛冶職で関与 |
| 黒森諸氏族 | 森民と精霊信仰の共同体 | 森の侵食、精霊沈黙、都市不信 | シィル、獣道、魔物情報で関与 |
| 裏市網 | 国境を越える非合法流通 | 密輸、偽造、借金、逃亡 | ガロ、禁制品、逃走路で関与 |

### 年表の例

| 年 | 出来事 | 主な影響 |
|---:|---|---|
| 1000 | 主人公誕生 | 出身、血統、初期関係が決まる |
| 1003 | 灰境地方で不作 | 食料圧の基礎値が上がる |
| 1005 | 王都で王位継承争い | 辺境への命令が混乱する |
| 1007 | 黒森で獣の大移動 | 魔物圧が上がる |
| 1008 | 白燭神殿で異端審査強化 | 神殿ルートの危険増加 |
| 1009 | 東方商人が食料買い占め | 商人組合の影響拡大 |
| 1010 | プロトタイプ開始時期 | 灰境地方に難民と異常の噂が流れる |
| 1011 | 王国軍の再編 | 守備隊の徴用や検問が厳しくなる |
| 1012 | 鉱山跡で遺物発掘 | 遺物・異界品イベントが増える |
| 1013 | 北方部族との小競り合い | 亜人差別、難民、傭兵イベント増加 |
| 1015 | 黒い封蝋の文書が各地で記録される | 異常の匂わせが国家規模になる |

年表は固定された一本道ではない。
プレイヤーの行動や周回記録により、一部の事件は遅れる、早まる、別の形で発生する。

### 国家イベント

国家イベントは、地方の生活に間接的に影響する。

| イベント | 発生国 | 地方への影響 | 干渉方法 |
|---|---|---|---|
| 食料徴発令 | 王都中央 | 村の食料が減り、食料圧上昇 | 文書改ざん、遅延、村への警告 |
| 検問強化令 | ヴェルツ辺境領 | 移動困難、逃亡難化 | 通行証、賄賂、裏道、守備隊関係 |
| 異端審査布告 | 白燭教圏 | 神殿が天賦や遺物に敏感になる | 神殿信頼、記録隠蔽、密告 |
| 食料価格操作 | 東方連邦 | 商人組合が強くなる | 倉庫不正暴露、裏取引、護衛 |
| 森境界封鎖 | 黒森諸氏族 | 採集・狩猟が難しくなる | シィルとの関係、精霊儀礼 |
| 鉱山再調査 | 地底鉱山都市群 | 遺物・職人・密輸イベント増加 | 鉱山案内、遺物鑑定、密輸 |
| 難民流入 | 北方部族圏 | 配給争い、差別、治安悪化 | 仲裁、保護、追放、利用 |
| 裏市封鎖 | 裏市網 | 逃走路と密輸が高騰 | ガロとの関係、別ルート開拓 |

### 干渉度

主人公の行動は、歴史イベントに対して干渉度を持つ。

| 干渉度 | 内容 | 例 |
|---|---|---|
| 0 | 無関係 | 何も知らずに通り過ぎる |
| 1 | 目撃 | 噂や痕跡を記録する |
| 2 | 局所干渉 | 1人のNPCや小さな倉庫を救う |
| 3 | 地方干渉 | 村、神殿、守備隊の判断を変える |
| 4 | 勢力干渉 | 商人組合や神殿派閥の動きを変える |
| 5 | 歴史干渉 | 年表上の事件が遅れる、早まる、別名で記録される |

プロトタイプでは干渉度0から3までを扱う。
本編では干渉度4以上を、章の結末や周回解放で扱う。

### 歴史イベントの構造

各歴史イベントは、以下のデータを持つ。

| 項目 | 内容 |
|---|---|
| 年 | 発生する年 |
| 地域 | 影響を受ける場所 |
| 勢力 | 関係する国・組織 |
| 原因 | 飢饉、戦争、政治、魔物、異常 |
| 表面イベント | プレイヤーが見る出来事 |
| 裏事情 | 記録や調査で分かる事情 |
| 干渉方法 | 何をすれば変えられるか |
| 結果 | 成功・失敗・放置時の変化 |
| 周回記録 | 次周に残る情報 |

### イベント例: 食料徴発令

| 項目 | 内容 |
|---|---|
| 年 | 1010 |
| 地域 | 灰麦村、ヴェルツ |
| 勢力 | 王都中央、ヴェルツ行政庁、守備隊 |
| 原因 | 王都の食料不足と軍再編 |
| 表面イベント | 村長が都市への食料供出を命じる |
| 裏事情 | 命令書の封蝋が通常と違う |
| 干渉方法 | 書記として台帳を遅らせる、村に警告する、商人に売る |
| 成功結果 | 村の食料が少し残る。行政庁の疑念上昇 |
| 失敗結果 | 村の食料圧上昇。ミラや村人の危機上昇 |
| 周回記録 | 食料徴発令の発生日、封蝋の違和感 |
